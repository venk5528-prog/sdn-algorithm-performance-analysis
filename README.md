# sdn-algorithm-performance-analysis
Perfomance analysis of SDN algorithms using python ,pandas  and numpy and extract fingerprints and analyze the suitable algorithm for deployment in controller

overview:
This repository presents the perfomance analysis of 7 algorithms used in SDN controller which are with fingerprints,
The aim is to analyze each algorithm and extract fingerprints with metrics like network perfomancce,intelligence , strength , limitations and suitbality for deployment
Analysis supports the deployment and run time efficiency of controllers

Tools used: Python, pandas,numpy, matplotlib

## Algorithms Included

- A*
- Ant Colony Optimization (ACO)
- Genetic Algorithm (GA)
- Particle Swarm Optimization (PSO)
- ASCON
- RBFT
- SSSP 2025(efficient than dijkstra)
